# 🚗 AVR Paros Transfer — Business Website

🔗 Live Website: https://www.avrparostransfer.com/

A production-ready business website developed for a transportation service company in Paros, Greece.

Built using HTML, CSS, and JavaScript, with a focus on performance, usability, and clear service presentation.

---

## 🚀 Overview

AVR Paros Transfer is a static business website designed to provide clear service information, booking contact details, and a professional digital presence for a local transportation company.

The primary goals were:

- Clean and trustworthy UI
- Fast loading performance
- Mobile-first responsiveness
- Clear service communication
